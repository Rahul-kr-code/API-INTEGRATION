##This project is a simple and responsive web application that demonstrates API integration using JavaScript. The application fetches random dad jokes from a public API and displays them dynamically on the webpage.

It is designed as part of an internship task to showcase the ability to work with external APIs, handle asynchronous data, and create a responsive user interface.

🚀 Features
Fetches data from a public API in real-time
Displays dynamic content without page reload
Responsive and user-friendly UI
Loading and error handling support
Clean and minimal design
🛠️ Technologies Used
HTML5
CSS3
JavaScript (ES6)
Fetch API
🔗 API Used

This project uses the icanhazdadjoke API to fetch random jokes.

Endpoint:
https://icanhazdadjoke.com/

⚙️ How It Works
User clicks the "Get Joke" button
